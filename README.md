# 외장하드 바탕화면 패널 (External Desk Panel)

외장하드를 컴퓨터에 꽂으면, 화면 오른쪽 1/4 영역에 그 외장하드 전용
"미니 바탕화면" 패널이 자동으로 뜹니다. 여러 개를 동시에 꽂으면 그 영역이
세로로 나눠져 각각의 패널이 됩니다. 뽑으면 해당 패널만 사라지고, 남은
패널들이 다시 영역을 나눠 씁니다.

컴퓨터 안(C 드라이브 등)에 저장된 파일과, 외장하드에 저장된(=컴퓨터가
고장 나도 살아있는) 파일을 화면에서 시각적으로 구분해서 관리하기 위한
프로그램입니다.

## 요구 사항

- Windows 10/11
- Python 3.9 이상 (설치 시 "Add Python to PATH" 체크)
- tkinter는 파이썬 기본 설치에 포함되어 있어 별도 설치 불필요
- 트레이 아이콘 기능을 위해 아래 두 패키지 필요:

```
pip install -r requirements.txt
```

(pystray, Pillow 없이도 실행은 되지만, 그 경우 트레이 아이콘 없이
백그라운드로만 동작하고 "등록/설정/종료" 메뉴에 접근할 방법이 없으니
설치를 권장합니다.)

## 실행

```
python main.py
```

처음 실행하면 트레이(작업표시줄 오른쪽 하단, 숨겨진 아이콘 표시 화살표
안에 있을 수 있음)에 파란색 외장하드 모양 아이콘이 나타납니다.

## 사용법

### 1. 외장하드 처음 등록하기

두 가지 방법이 있습니다.

- **자동**: 등록 안 된 외장하드를 꽂으면 "등록하시겠습니까?" 팝업이 뜹니다. 예를 누르면 등록 창이 열립니다.
- **수동**: 트레이 아이콘 우클릭 → "외장하드 등록"

등록 창에서:
1. (자동 팝업이 아니라 수동으로 열었다면) 등록할 드라이브 선택
2. 패널에 표시할 이름 입력 (예: "작업용 외장하드")
3. "+ 폴더 추가" / "+ 파일 추가"로 패널에 보이고 싶은 폴더·파일을 고름
4. "등록" 클릭 → 그 외장하드가 연결되어 있다면 바로 패널이 뜸

### 2. 패널 사용하기

- 아이콘 더블클릭 → 해당 폴더/파일 열기 (탐색기/기본 프로그램 실행)
- 아이콘 우클릭 → 열기 / 이름 바꾸기 / 패널에서 삭제 (실제 파일은 삭제 안 됨)
- 빈 공간 우클릭 → 폴더/파일 추가
- 제목 표시줄 더블클릭 또는 우클릭 → 패널 이름 바꾸기

### 3. 설정 (트레이 아이콘 우클릭 → 설정)

- 패널을 띄울 모니터 선택 (여러 모니터 사용 시)
- 새 외장하드 자동 감지 팝업 켜기/끄기
- 윈도우 시작 시 자동 실행 켜기/끄기
- 등록된 외장하드 순서 변경 (여러 개 연결 시 위→아래 순서), 등록 해제

### 4. 컴퓨터를 켤 때부터 자동으로 뜨게 하기

설정 창에서 "윈도우 시작 시 자동 실행"을 체크하세요. 사용자 시작프로그램
폴더에 등록되며 관리자 권한은 필요 없습니다. 이렇게 해두면, 부팅 후
로그인해서 컴퓨터를 쓸 수 있는 상태가 되자마자 이미 꽂혀있는 외장하드의
패널이 자동으로 뜹니다.

## 동작 원리 (왜 드라이브 문자가 아니라 "볼륨 시리얼 번호"로 인식하나요?)

외장하드를 뺐다가 다시 꽂으면 드라이브 문자(D:, E: 등)가 매번 똑같이
배정된다는 보장이 없습니다. 그래서 이 프로그램은 각 볼륨 고유의
"볼륨 시리얼 번호"를 등록해두고, 몇 초마다 현재 연결된 드라이브들을
스캔해서 이 번호가 일치하는 걸 찾는 방식으로 "그 외장하드가 지금
연결되어 있는지"를 판단합니다. 드라이브 문자가 바뀌어도 문제없이
같은 외장하드로 인식합니다.

## (선택) 진짜 설치 프로그램(.exe)으로 만들기

지금까지처럼 `python main.py`로 실행하는 대신, 파이썬이 없어도 더블클릭
한 번으로 켜지는 `.exe` 파일로 만들 수도 있습니다. 원하시면 아래 두
단계를 진행하세요. (이미 파이썬이 설치되어 있는 지금 컴퓨터에서 진행)

### 1단계: exe 파일 만들기

`external_drive_panel` 폴더 안의 **`build_exe.bat`** 파일을 더블클릭하세요.
자동으로 필요한 패키지를 설치하고, `dist` 폴더 안에
**`ExternalDeskPanel.exe`** 를 만들어줍니다. 이 파일 하나만 다른 곳으로
옮겨서 더블클릭해도 바로 실행됩니다 (파이썬 설치 여부와 무관).

### 2단계 (선택): 진짜 "설치 마법사" 만들기

윈도우 프로그램들처럼 "다음 > 다음 > 설치" 방식의 설치 프로그램을
원하시면:

1. [Inno Setup](https://jrsoftware.org/isinfo.php) (무료)을 다운로드/설치
2. 이 폴더 안의 **`installer.iss`** 파일을 Inno Setup으로 열기
3. 상단의 "Compile" 버튼 클릭
4. `Output` 폴더 안에 **`ExternalDeskPanel_Setup.exe`** 생성됨

이 `ExternalDeskPanel_Setup.exe`를 실행하면, 설치 위치 지정, 시작 메뉴
등록, 바탕화면 바로가기 생성, "윈도우 시작 시 자동 실행" 체크박스,
제어판(설정 > 앱)에서의 제거 항목까지 — 일반적인 윈도우 프로그램
설치와 똑같은 경험을 제공합니다. 관리자 권한도 필요 없습니다.

## 이번 업데이트로 추가된 것

- **드래그 앤 드롭**: 탐색기에서 파일/폴더를 패널로 끌어다 놓으면
  - 이 외장하드 안의 항목 → 즐겨찾기로 자동 등록
  - 다른 드라이브의 항목을 패널 빈 곳에 놓으면 → 정확한 폴더 위에 놓으라는 안내
  - 다른 드라이브의 항목을 패널 안 특정 폴더 위에 놓으면 → 그 폴더로 복사할지 확인 후 복사 (하이라이트 표시, 이름 충돌 시 덮어쓰기/건너뛰기/취소 선택)
  - **주의**: 이 기능은 `tkinterdnd2` 패키지가 설치되어 있어야 동작합니다 (`pip install -r requirements.txt`에 포함됨). 설치 안 돼 있으면 드래그 앤 드롭만 빠지고 나머지는 정상 동작합니다.
- **드라이브 루트 고정 탭**: 탭 줄 맨 앞에 `💾 D:` 같은 고정 탭이 항상 있어서, 클릭하면 그 외장하드의 맨 바깥(루트)으로 바로 이동
- **이름 자동화**: 패널/트레이에 표시되는 이름은 이제 사용자가 직접 정하지 않고, 드라이브 문자 + 외장하드 볼륨 이름으로 항상 자동 계산됩니다
- **화면 영역 설정**: 패널 툴바의 ⚙ 아이콘(또는 트레이 → 설정 → "화면 영역 설정 열기")에서, 모니터를 고르고 화면을 원하는 격자로 나눈 뒤 칸 하나를 선택하면 패널들이 항상 그 자리에 뜹니다. 여러 외장하드가 그 칸을 세로/가로 중 어떻게 나눠 쓸지, 가장자리 여백은 얼마로 할지도 설정 가능
- **트레이 메뉴 재구성**: 등록된 외장하드마다 하위 메뉴가 생겨서 "패널 숨기기/다시 보이기", "등록 해제"를 바로 할 수 있습니다

- **공통 상단바**: 화면 영역 맨 위에 프로그램 이름과 함께 ⚙(화면 영역 설정) / 👁(숨김 항목) / － ＋(아이콘 크기) / ⊞ ☰(보기모드) 버튼이 하나로 모여 있고, 여기서 바꾸면 등록된 모든 외장하드 패널에 한 번에 적용됩니다. (뒤로/앞으로/위로/홈 이동과 탭·주소표시줄은 각 패널마다 개별로 유지됩니다)
- **더 정확한 화면 영역 계산**: 이제 작업표시줄을 제외한 실제 "작업 영역" 기준으로 계산해서, 여백을 0으로 둬도 패널이 작업표시줄과 겹치지 않습니다.
- **더블클릭 버그 수정**: 아이콘 선택 시 전체를 다시 그리지 않도록 고쳐서, 폴더/파일 더블클릭이 바로 되도록 수정했습니다.
- **고해상도(DPI) 흐림 현상 수정**: 프로그램이 시작할 때 윈도우에게 "고해상도를 직접 처리하겠다"고 알려줘서, 화면이 흐릿하게 확대되지 않고 선명하게 보이도록 했습니다.
- **패널 제목 중복 제거**: 별도 제목표시줄을 없애고, 탭 줄의 고정 탭 하나가 드라이브 이름 표시와 "루트로 이동" 기능을 겸합니다.
- **파일도 즐겨찾기 추가 가능**: 폴더뿐 아니라 파일도 우클릭 → "⭐ 즐겨찾기에 추가"로 등록할 수 있습니다.
- **외장하드 꺼내기 버튼**: 탭 줄의 드라이브 이름 옆 ⏏ 버튼으로 안전하게 제거를 시도합니다. 일부 USB 외장 HDD(특히 UASP 방식)는 소프트웨어 꺼내기가 지원되지 않을 수 있으며, 이 경우 실패 메시지와 함께 "작업표시줄의 하드웨어 안전 제거 아이콘을 이용해달라"는 안내가 뜹니다.
- **재연결 시 항상 홈에서 시작**: 예전엔 마지막으로 보던 폴더를 기억해서 다시 보여줬는데, 이제는 외장하드를 뽑았다 다시 꽂으면 항상 즐겨찾기 홈(드라이브 루트)부터 보여줍니다.

## 참고 / 한계

- 이 프로그램은 Windows 전용입니다 (ctypes로 Windows API를 직접 호출).
- 외장하드 안의 폴더 위치를 옮기면 (드라이브는 그대로, 상대 경로만 변경)
  등록된 항목이 "❓" 표시로 나올 수 있습니다. 이 경우 삭제 후 다시
  추가해주세요.
- pystray가 설치되어 있지 않으면 트레이 아이콘 없이 실행되며, 이 경우
  등록/설정 창을 열 방법이 없으니 `pip install -r requirements.txt`를
  먼저 실행해주세요.
- exe 파일로 배포하고 싶다면 `pyinstaller --onefile --windowed main.py`
  등을 활용할 수 있습니다 (추가 설정 필요할 수 있음).
