EXTERNAL DRIVE PANEL - Windows x64

실행
설치본: ExternalDrivePanel-win-Setup.exe를 실행하세요. 이후 시작 메뉴/바탕화면 바로가기로 실행합니다.
포터블 ZIP:
1. ZIP 전체를 한 폴더에 풀어주세요.
2. ExternalDrivePanel.exe를 실행하세요. 함께 있는 DLL과 licenses 폴더를 유지하세요.
3. .NET 실행 환경은 포함되어 있으므로 별도 런타임 설치는 필요하지 않습니다.
4. 연결된 드라이브의 등록 알림 또는 트레이 메뉴에서 사용할 드라이브를 등록하세요.
5. 종료는 트레이 아이콘의 '종료'를 사용하세요.

주요 사용법
- 드라이브 이름 클릭: 드라이브 루트 열기 / 이름 우클릭: 볼륨 이름 변경
- 집: 즐겨찾기 홈 / 별표+: 선택 항목 또는 현재 폴더 즐겨찾기 추가
- 파일 선택 후 Space: 미리보기 / Esc: 미리보기 닫기
- 검색: 이름 일부, *.pdf, .jpg, ext:txt 입력 후 Enter
- 파일 삭제는 실제 파일 작업입니다. 즐겨찾기 제거와 구분해주세요.

설정 및 작업 보호
- 설정 위치: %APPDATA%\ExternalDeskPanel\config.json
- 동일한 사용자 설정을 쓰는 앱은 중복 실행되지 않습니다.
- 파일 작업 중 종료/꺼내기는 확인 후 진행 중인 작업의 완료를 기다립니다.
- Windows에서 강제 종료하거나 전원을 끄는 경우까지 보호하지는 못합니다.
- 장치를 물리적으로 분리하기 전에 복사/이동/압축 작업을 완료해주세요.

알려진 제한
- Windows 11 x64에서 검증했습니다. 다른 PC/Windows 버전은 실제 확인이 필요합니다.
- 리사이즈 중 시각적 떨림이 남을 수 있습니다.
- 매우 큰 폴더의 최초 목록 표시나 아이콘 생성에는 시간이 걸릴 수 있습니다.
- 미리보기/Windows 메뉴의 지원 범위는 설치된 코덱과 프로그램에 따라 다릅니다.
- 포터블 ZIP은 자동 업데이트 대상이 아닙니다. 자동 업데이트는 Setup.exe 설치본을 사용하세요.
- 메인헤더 설정의 'Windows 시작 시 자동 실행'으로 현재 사용자 자동 실행을 켜거나 끕니다.
- 설치본은 시작 20초 후 및 6시간마다 새 버전을 확인합니다.
- 다운로드가 준비되면 패널 하단의 '업데이트 후 다시 시작'을 눌러 확인해주세요.
- 파일 작업 완료와 설정 저장을 기다린 뒤 새 버전으로 자동 재실행됩니다. 일반 종료에서는 업데이트하지 않습니다.
- 개인 배포본은 코드 서명이 없어 Windows의 평판 기반 경고가 나타날 수 있습니다.
